## 關於

「食在有愛」（諧音「實在有愛」）是國立台南大學在職碩班團隊與 NPOChannel 公益整合平台合作的公益消費計畫。

我們相信，真正的關懷不只是理念，而是可以被實踐的行動。透過販售在地特色果乾與公益禮盒，建立「購買即捐贈」的公益循環，讓每一次消費都能成為弱勢家庭孩童的營養支持。

## 果乾公益組

### 商品內容

* 芭樂果乾
* 芒果果乾
* 梅子乾
* 每包 100g
* 共 8 包組合

### 公益承諾

每售出 1 組果乾公益組，即捐出 1 份營養菜品給弱勢家庭孩童。

讓愛心不只是一次性的捐款，而是透過日常消費持續發揮影響力。
